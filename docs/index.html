2. Reverse Engineering the Android Binary

Inside Sentinel-3-Homeworld-v1-4-2.apk, the native C++ game library (lib/x86/libSentinel3Android.so) shipped with unstripped symbol names. That allowed our analysis script to jump straight to key functions and read raw static data tables directly out of the ELF binary into tools/extract_apk_assets.py and scripts/game_data.gd.

g_EnemyWavePatternData @ 0x1e3ab0 20 wave patterns × 30 bytes (600 bytes total), each byte indexing enemy types 0..19. assets/data/campaign_data.json

The Disguised-PNG & UV-Coordinate Discovery

Two clever quirks inside the APK assets needed handling in tools/extract_apk_assets.py:

  • .mp3 files that are actually PNGs: Older Android versions compressed non-media assets or choked on large uncompressed APK entries, so the original developers named 80+ PNG texture atlases *.mp3 to bypass Android's asset compression! Our extractor inspects the first 8 bytes for the \x89PNG\r\n\x1a\n magic header and saves them as real .png files.
  • Normalized UVs over pixel bounds in .xml atlases: Some atlases (such as Behemoth) were downscaled compared to the XML's pix dimensions, but every XML region included normalized value coordinates (0.0..1.0). Multiplying those UVs by the actual PNG width and height yields exact pixel rectangles regardless of resolution tier.

3. What Was Reused vs. Mapped vs. Built New

An interesting discovery about Sentinel 3 on Android is that the base 32 MB APK didn't contain everything: a separate ~67 MB download pack held the Campaign 1 tilesets and 1×1 turret sheets. Here is how each piece was sourced:

Original Audio & Maps Reused 100%

All 29 .tmx map files (tile layers, EnemyPath / FlyingEnemyPath waypoints, LinkedDestroyable barrier links, SpecialGameObjects drop points and Alien Eggs) and all 51 .ogg sound effects & music came straight from the APK.

Heavy Turrets, Hero & Creeps Reused 100%

All enemy sprite sheets (MutantWalker*, Arachnid*, Flyer*, Resistant*, SlimerWalker, Behemoth, all 5 Bosses), the Commander (Hero1), EggMound, and both 64-frame 2×2 heavy turret sheets (ArtilleryNormal/Max, PoisonNormal/Max) are original assets.

Campaign 1 Tilesets Remapped

While Campaign 2 tilesets (TS_BaseBG6, TS_BGSet05/06, TS_BGElements06/07) shipped inside the APK, Campaign 1 names (BaseBG1..5, BGSet01..04) share identical 256×256 and 512×512 grid layouts — so TILESET_FALLBACKS maps them automatically while still supporting optional HD/cache packs if dropped into Downloads.

1×1 Turrets, Barriers & Drone Built in Python

Because the 1×1 turret/barrier textures lived in the missing external OBB cache (and Python lacked Pillow), extract_apk_assets.py includes a custom zero-dependency RGBA Canvas + zlib PNG encoder that procedurally draws a 512×512 turrets_sheet.png with L1–L4 pedestals and rotating barrels.

Godot 4.7 Engine & Simulation Built New

All gameplay code was written fresh in typed GDScript: GameData, MapRenderer, GameManager, TowerEntity, EnemyEntity, BarrierEntity, CommanderEntity, HarvestDroneEntity, HUD, and automated tests.

4. Architecture & Technical Decisions

Key Architectural Choices

  • Compiled JSON data over hardcoded scene instances: Parsing .tmx files in Python into assets/data/maps.json avoids XML parsing overhead at runtime and lets MapRenderer switch instantly between any of the 29 levels via a single dropdown.
  • Programmatic CanvasItem._draw() rendering: Towers, enemies, health bars, range rings, Booster tethers, lasers, projectiles, and path previews draw directly inside lightweight Node2D scripts rather than dozens of nested Sprite2D / CollisionShape2D children per creep. Even when 100+ Swarm Arachnids spawn, frame times stay crisp on mobile and desktop alike.
  • Single 960×540 logical canvas for Desktop & Mobile: Configured in project.godot with canvas_items/expand stretch and emulate_touch_from_mouse / emulate_mouse_from_touch. Both tap-to-place and click-drag-release share the exact same _input() pipeline.
  • Step-function simulation hook for testing: Splitting step_simulation(dt) out of _process(delta) allows tests/verify_gameplay.gd to fast-forward entire waves in under a second deterministically.

5. Engineering War Stories: Real Bugs Solved

Bug 1: Frozen Missile & Poison Projectiles

Symptom: Green Poison orbs and yellow Missile dots sometimes froze in mid-air above towers.

Cause: Projectiles held a dictionary reference p["target"] to their target EnemyEntity. When another tower killed and queue_free()'d that enemy mid-flight, assigning var tgt: EnemyEntity = p["target"] inside _update_projectiles() threw a Godot 4 runtime type error on the freed object before is_instance_valid(tgt) could run, aborting the projectile loop every frame.

Fix: Clear p["target"] = null inside _on_enemy_died() and _on_enemy_reached_end(), validate is_instance_valid(tgt_var) on an untyped Variant before casting as EnemyEntity, and add a 4.0s safety TTL.

Bug 2: Artillery & Poison Facing the Wrong Direction

Symptom: 2×2 Artillery cannons and Poison nozzles looked turned away from the enemies they shot.

Cause: Inspecting the 64-frame sheets (ArtilleryNormal.png, PoisonNormal.png) showed frames 0..31 rotate counter-clockwise on screen starting from Left (0 = Left, 8 = Down, 16 = Right, 24 = Up), while frames 32..63 are muzzle-flash firing frames. Our initial formula rotated clockwise from Up and locked Level 3 towers permanently onto frames 32..63.

Fix: Switched to wrapf(PI - angle_rad, 0.0, TAU) in TowerEntity.get_native_dir_idx(), gated frames 32..63 on active recoil (_recoil > 0.35), and required towers to turn within 0.28 rad of their target before firing. At the same time, we aligned EnemyEntity._draw() to the actual 16×5 heading-row / walk-column layout of the MutantWalker and Arachnid sheets.

Bug 3: Godot 4.7 Strict Variant Type Inference & Autoload Tests

Godot 4.7 rejects := when the right-hand side is an untyped JSON dictionary lookup or array element (requiring explicit types like var camp: Variant = ...), and running tests via -s test.gd bypasses [autoload] singletons. Converting tests/verify_gameplay.gd to extend Node inside verify_gameplay.tscn resolved autoload initialization cleanly.

6. Tactical Player's Guide (How to Play & Win)

Controls (Desktop & Mobile)

  • Build a Turret: Click/tap a turret in the right sidebar, then tap any highlighted green map tile (or press and drag directly onto the map and release).
  • Upgrade / Sell: Tap any built tower to open its range ring and Tactical Inspector (Upgrade, or Sell for 80% refund).
  • Command the Hero Mech: Tap the Commander (or click MOVE CMDR) then tap anywhere on the battlefield to reposition. Use STOMP for heavy AoE damage + 50% slow (12s cooldown).
  • Orbital Weapons: Click an Orbital button under Sentinel Orbital Weapons and tap the target area to strike (drains Ship Energy).
  • Keyboard Shortcuts: Space starts the next wave; Esc or Right-Click cancels build/target/move mode and clears selection.

6 Pro Tips for High Scores & Harder Difficulties

  1. Bank in Multiples of $100 for Free Interest: At the end of every wave, you earn floor(cash / 100) * 5 (+5% interest, plus +$10 wave bonus). Waiting to spend $20 right after a wave instead of right before it can push your cash over a $100 threshold for free bonus credits!
  2. Move Your Commander Next to Key Choke Clusters: Commander's Morale Aura (96px radius) grants nearby non-Booster towers +25% damage and +20% fire rate — plus the Commander regenerates HP after 3s out of combat and respawns after 12s if defeated.
  3. Let Slow & Poison Work Together: Slow towers cut ground creep movement by 20%–35% for 3s, keeping enemies inside Poison's 4-second burn DoT (up to 80 DPS at L4!) and Artillery splash zones far longer.
  4. Booster Pool Sharing Math: One Booster divides its pool (35% at L1 up to 900% at L4!) across nearby offensive towers while also boosting their range (+12%..+24%). Even with multiple towers in range, upgrading a central Booster multiplies your entire killbox.
  5. Toggle Your Harvest Drone Smartly: Between tough waves, your Drone automatically generates +$5 Cash & +6 Energy per trip. When a forward Barrier takes heavy damage, click HARVEST to switch it into Repair Mode (+25 HP/tick) — and don't be afraid to sell forward towers near a falling Barrier (80% refund!) to reinforce the Base line behind it.
  6. Respect Air & Damage Resistances: Bombs, Slows, Poison, and Artillery only hit Ground creeps — always build Laser, Missile, Beam, or Sniper coverage before Flyer waves! Similarly, Resistant creeps take only 25% damage from their matching type (Laser / Fire / Slow), so mix Kinetic (Sniper) or Explosive (Bomb/Missile/Artillery) damage into your killzones.

9. Modding & Editing Cookbook

Because the game keeps data cleanly separated from behavior, almost any mod takes only a few lines:

Recipe A: Rebalance or Add a Turret

Edit TOWER_ORDER and TOWER_DEFS in scripts/game_data.gd, then add any special firing logic in scripts/entities/tower.gd inside _fire_at().

"railgun": {
    "id": "railgun", "name": "Railgun", "short": "RAIL",
    "footprint": 1, "targets_air": true, "targets_ground": true,
    "costs": [120, 140, 180, 350],
    "damage": [95.0, 210.0, 420.0, 900.0],
    "reload": [1.4, 1.3, 1.2, 1.0],
    "range": 195.0, "splash": 0.0, "slow_pct": 0.0, "dot_dps": 0.0,
    "buff_pool": 0.0, "dmg_type": "kinetic", "sheet_row": 4,
    "color": Color(1.0, 0.3, 0.45), "sfx": "Fire_SniperTower",
    "desc": "Custom modded armor-piercing railgun."
}

Recipe B: Change Starting Cash, Wave Order, or Interest Rate

  • Adjust INTEREST_RATE := 0.05 or SELL_REFUND_RATIO := 0.80 at the top of scripts/game_data.gd.
  • Edit individual mission starting_cash, starting_energy, waves, or wave_patterns inside assets/data/campaign_data.json (note: re-running extract_apk_assets.py regenerates JSON from the APK).

Recipe C: Edit or Create New Maps

Open any assets/maps/Map*.tmx in Tiled Map Editor (keep tile grid 21×16 at 32×32, preserve EnemyPath / Destroyables / SpecialGameObjects object groups and Path / Reserved layer properties), then either re-run the map parser in tools/extract_apk_assets.py or edit the compiled entry in assets/data/maps.json.

Recipe D: Use Original Campaign 1 HD Cache Assets (If You Have Them)

If you ever obtain the original Android external cache pack (e.g. *sentinel*.obb / *hdaddon*.zip) and drop it into your Downloads folder, re-run: 

python tools/extract_apk_assets.py

find_source_zips() automatically detects companion packs in Downloads and replaces the fallback Campaign 1 tilesets with the original Campaign 1 textures without touching any GDScript!

10. Testing & Verification

Always run the automated gameplay suite after modding or editing simulation code:

godot --path . res://tests/verify_gameplay.tscn

It boots the real scenes/main.tscn scene, checks all 42 assertions (economy, upgrade math, Booster & Commander auras, 80% sell refunds, Wave 1 simulation, Orbital Laser, freed-target projectile clearing, 32-direction Artillery alignment, and Campaign 2 Egg loading), and exits with code 0 on ALL_TESTS_PASSED.
